Template for writing a new subunit class.

Save as subunits/<Name>.py - the subunits package imports it automatically.

`aliases` is the list of names the user can type after --subunit/-s. They are
matched case-insensitively and ignoring spaces and underscores, so "hollow
sphere", "Hollow_Sphere" and "hollowsphere" all resolve to the same class.
The first alias is the canonical name and is the one used in error messages.

Every subunit derives from Subunit (see Subunit.py), which declares the methods
below. A subunit that leaves one out cannot be instantiated, and one without
its own aliases raises a TypeError as soon as it is imported.

The dimensions are the named arguments of __init__, in the order the user
gives them after --dimension/-d. Give them descriptive names (radius, length,
...): they appear in the error message when the wrong number is given, and
can be used as keywords, e.g. Cylinder(radius=20, length=100). There is no
need to check their number - Python does that.

NOTE: getPointDistribution() and checkOverlap() must describe the SAME body.
The generating box must enclose the subunit, and getVolume() must return the
volume of the subunit itself - not of the box.
